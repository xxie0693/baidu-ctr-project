## 一、本周核心工作内容
1. **构建模型训练数据管线**：从 SQLite 数据库中高效抽取了约 400 万条样本，使用 LabelEncoder 完成了高基数特征的编码，并按 7:2:1 划分了训练、验证和测试集。
2. **传统机器学习模型训练**：
   - 实现了逻辑回归（LR）作为基线，AUC 为 0.6120。
   - 实现了 LightGBM 树模型，在测试集上 AUC 达到了 **0.7337**，LogLoss 为 0.4050，训练仅耗时 23 秒。
3. **深度学习模型构建**：基于 PyTorch 从零实现了 Wide & Deep 联合模型，在 CPU 环境下训练 3 个 Epoch，AUC 提升至 0.7187，且 Loss 仍在稳定下降。
4. **模型可解释性与 A/B 测试**：
   - 引入 SHAP 树解释器对 LightGBM 进行了特征归因分析，输出了特征影响蜂群图。
   - 基于模型预测结果，设计了模拟 A/B 测试方案，测算出精准定向高潜人群可带来大盘 CTR 约 8.85% 的相对提升。

## 二、业务洞察与发现
- **关键特征归因**：SHAP 结果显示，`app_id`、`site_id` 以及匿名素材特征 `C21`、`C14` 是影响点击的最核心因素。这证明在广告投放中，“场景（媒体）与素材的匹配度”远比简单的用户属性更重要。
- **策略倾斜**：模型能有效识别高转化潜力的流量，建议在实际投放中，对高潜广告位（如 `banner_pos=1`）和凌晨时段（1:00-2:00）进行出价提权。

## 三、遇到的问题与解决
- **SQL 随机抽样性能瓶颈**：使用 SQLite 原生的 `RANDOM()` 进行抽样时，全表扫描导致耗时极长（3 分钟仅抽出 22%）。通过改为基于 `rowid` 取模的抽样方式，将加载时间缩短至 15 秒内。
- **中文图表乱码**：SHAP 绘图时因 matplotlib 默认字体不支持中文导致文字显示为方块。通过配置 `plt.rcParams['font.sans-serif']` 全局引入中文字体解决。
